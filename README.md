RSA密钥交换
----------
客户端生成一个随机对称密钥，并通过服务器的RSA公钥加密后发送，服务器用私钥解密后获得密钥。

DH(迪菲-赫尔曼密钥交换)
--------------------
* 大质数p, 生成元g

* 双方公开约定的大质数p和生成元g
* 发送方生成私钥a, 并计算公钥A(p, g, a),后发送A
* 接收方生成私钥b, 并计算公钥B(p, g, b),后发送B, 并计算共享密钥共享密钥s(p, b, A)
* 发送方计算共享密钥s(p, a, B)

Transformer
-----------
如何让计算机高效、并行地理解长文本中词与词之间的复杂关系。
核心思想：自注意力机制
自注意力机制让模型能够动态地、并行地捕捉句子内部的长距离依赖关系。
这正是RNN（循环神经网络）等老一代架构的痛点，因为它们必须按顺序处理，导致长距离信息容易"遗忘"。
