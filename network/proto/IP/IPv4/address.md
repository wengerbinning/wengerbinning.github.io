### E类地址

在32为地址中， 前五位位为11110的为B类地址：总共约有1亿个地址；


其中A、B、C三类用于单播地址， D类用于组播地址， E类为保留地址。


## 地址管理

在管理地址中, 我们会划分一组地址来共组织使用, 这里引入子网掩码的概念, 将地址划分为网络号
与主机号, 每一个网络号代表一组地址,称为一个子网, 其中主机号为0的地址保留,作为子网的标识
主机号最大的地址作为广播地址.

### 组播地址

组播地址是用来一对多的场景.

#### 本地链路组播 (Link-local Multicast)

二层网络内使用

```
(0b) 1110 0000 0000 0000 0000 0000 0000 0000 / 224.0.0.0
(0b) 1110 0000 0000 0000 0000 0000 1111 1111 / 224.0.0.255
```

* `224.0.0.1` - 所有主机（All Hosts）
* `224.0.0.2` - 所有路由器（All Routers）
* `224.0.0.5` - OSPF 路由器
* `224.0.0.6` - OSPF DR/BDR 路由器
* `224.0.0.9` - RIP v2
* `224.0.0.251` - mDNS（多播 DNS）

#### 全局组播 (Globally Scoped)

可以跨越互联网使用

```
(0b) 1110 0000 0000 0000 0000 0001 0000 0000 / 224.0.1.0
(0b) 1111 0110 1111 1111 1111 1111 1111 1111 / 238.255.255.255
```

#### 管理范围组播 (Administratively Scoped)

类似于私有地址

```
(0b) 1110 1111 0000 0000 0000 0000 0000 0000 / 239.0.0.0
(0b) 1111 0111 1111 1111 1111 1111 1111 1111 / 255.255.255.255
```

* `239.255.255.250` - SSDP(UPnP)
