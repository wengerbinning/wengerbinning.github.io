Internet Control Message Protocol (ICMP, 互联网控制报文协议)

* Type
* Code
* Checksum
* Data








ICMP Type
---------

*  0 - Echo Reply
*  3 - Destination Unreachable
*  4 - Source Quench
*  5 - Redirect
*  8 - Echo Request
*  9 - Router Advertisement
* 10 - Router Solicitation
* 11 - Time Exceeded
* 12 - Parameter Problem
* 13 - Timestamp Request
* 14 - Timestamp Reply




在ICMP协议中, 设备可能因为安全原因禁止PING操作:
* Windows默认禁止PING
* Windows默认禁止跨网段PING
